# PFA Current Website Snapshot

This repository contains a locally crawled snapshot of the People for Animals India website.

Source:
https://www.peopleforanimalsindia.org/

Purpose:
Reference/archive for the PFA website redesign and functional scoping exercise.

This is not the production website.

The `www.peopleforanimalsindia.org` directory contains the downloaded HTML pages and associated assets including images, videos, PDFs, CSS and JavaScript.
